# ShieldGuard Fumigation Website

A responsive, single-page fumigation and pest-control website built with plain HTML, CSS and JavaScript.

## Before publishing
1. Open `index.html`.
2. Search for `ShieldGuard` and replace it with your business name.
3. Search for `2348000000000` and replace it with your WhatsApp number in international format (Nigeria: `234` + number without the first `0`).
4. Replace the sample phone number, service area, working hours and any claims to match your business.
5. The hero image is hosted by Unsplash and requires an internet connection. You can replace its URL with your own image.

## Publish with GitHub Pages
1. Create a GitHub repository, for example `fumigation-website`.
2. Upload `index.html` (and this README if you want).
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)` folder, then save.
6. Wait for GitHub Pages to publish the site; the URL will appear on the Pages settings screen.

No build tools or dependencies are required.
